# Dhanush Raji — Portfolio starter

A responsive portfolio website with a professional layout and restrained futuristic visuals. Built with plain HTML, CSS, and JavaScript.

## Files
- `index.html` — page content
- `style.css` — design and responsive layout
- `script.js` — mobile navigation, year, and subtle pointer interaction

## Before publishing
1. Open `index.html` and replace all placeholder text such as `Add your degree / course`, `Your project name`, and `Add technology`.
2. Add only skills, education details, certifications, and projects that are accurate.
3. Add your real project repository URLs to each project card.
4. If you want an email contact button, add your email address yourself.
5. Open `index.html` in a browser to preview the site.

## Run locally
Double-click `index.html`, or open the folder in a code editor and use its local preview/live server.

## Publish with GitHub + Vercel
1. Create a new public repository on GitHub (for example, `dhanush-portfolio`).
2. Upload `index.html`, `style.css`, and `script.js` to the repository root.
3. Sign in to Vercel with GitHub and import the repository.
4. Keep the default settings for a static HTML site and select Deploy.
5. Once deployment succeeds, copy the generated `.vercel.app` URL and add it to your LinkedIn profile.

This package is a starter website, not a deployed/live website. Project and education placeholders must be replaced before sharing it with recruiters.
